Proposed stable surface

  

    
Preserved options: -n, --all, --min-score, --full, -c/--collection, --intent, --format, --full-path, --line-numbers, --explain, and typed lex:/vec:/hyde: query documents.

    
QMDX additions: --no-expand, --no-rerank, and --allow-degraded. Candidate depth remains an implementation/policy concern rather than a casual user option; the selected QMD pool size is visible in explanations.

    
Exit categories: 0 completed (including zero matches and allowed degradation), 2 invalid invocation/configuration, 3 local index/retrieval failure, 4 required remote inference failure, 5 unexpected internal failure.
